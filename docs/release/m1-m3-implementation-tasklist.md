# M1 → M3 实施任务单（可直接执行）

## 任务使用说明

- 状态建议：`TODO / DOING / DONE`  
- 每个任务都应在后台“功能开关中心”有对应开关结果与审计记录。  
- 每阶段切换前后都要执行回归测试并留截图。

---

## Phase M1（工具版上架）

### A. 开关与发布控制
- [ ] 应用预设：`m1_tool_launch`
- [ ] 核验关键开关：`点赞/评论/发布/群组/群聊` 全部关闭
- [ ] `mock_data_enabled` 关闭
- [ ] 导出并存档开关截图（首页、开关中心、日志）

### B. 审核材料
- [ ] 使用《微信审核提交文案模板》生成提审文案
- [ ] 填写体验路径（只含工具链路）
- [ ] 自检“不可触达社交路径”清单

### C. 自测清单
- [ ] 广场页可正常浏览
- [ ] 我的页可登录、查看账号和设置
- [ ] 时间线可新增/编辑/删除
- [ ] 无法进入群组、评论、点赞、发布

---

## Phase M2（资质与风控准备）

### A. 合规与资质
- [ ] 完成主体与备案/资质准备（按业务地监管要求）
- [ ] 完成隐私政策、用户协议、内容治理规则升级
- [ ] 审核后台管理员权限与操作审计流程

### B. 风控系统
- [ ] 接入内容审核策略（文本/图片/视频）
- [ ] 建立违规处理SOP（封禁、申诉、复核）
- [ ] 建立客服/运营巡检表（日常巡检）

### C. 功能分批放开（建议）
- [ ] 开启 `publish_entry_visible`
- [ ] 开启 `publish_submit_enabled`
- [ ] 保持 `groups_*` 相关关闭
- [ ] 根据数据评估是否开启 `square_scene_theater_visible`

---

## Phase M3（完整社交能力）

### A. 开关切换
- [ ] 应用预设：`m3_full_social`
- [ ] 核验 `groups_join_enabled/groups_chat_enabled/groups_create_enabled`
- [ ] 核验 `square_like_enabled/square_comment_enabled/square_share_enabled`
- [ ] 核验 `profile_social_enabled/social_profile_view_enabled`

### B. 运营策略
- [ ] 配置社交功能灰度方案（白名单/比例放量）
- [ ] 设置异常回滚预案（30分钟内可回切 M2）
- [ ] 设定核心监控指标（举报率、封禁率、消息审核命中率）

### C. 稳定性与安全
- [ ] 核验接口限流与滥用防护
- [ ] 核验日志留存与备份策略
- [ ] 完成一次全链路压测与故障演练

---

## 回滚任务（任意阶段可执行）

- [ ] 一键回切预设 `m1_tool_launch` 或 `m2_compliance_mode`
- [ ] 核验前端入口和后端接口双层封禁生效
- [ ] 通知运营暂停对应活动位
- [ ] 记录事件编号与恢复时间
